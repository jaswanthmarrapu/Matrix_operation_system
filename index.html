System Architecture & OOP Foundations

Encapsulated State

The system models matrices using an object-oriented Matrix class containing rows, columns, and a 2D data store with strict accessor methods.

Dimension Validation

Pre-execution checks enforce linear algebra rules ($r_A == r_B$ for addition/subtraction, $c_A == r_B$ for multiplication).

Immutability & Purity

Mathematical operations do not mutate the input operands; each calculation returns a newly allocated Matrix result object.
